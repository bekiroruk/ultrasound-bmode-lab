# Data directory

The raw PICMUS UFF file is intentionally excluded from Git because it is 76.7 MB and has its own attribution requirements.

Download and verify it from the immutable Zenodo record:

```bash
python scripts/download_picmus.py
```

Expected local path: `data/raw/PICMUS_carotid_cross.uff`.

See [`docs/real-data-provenance.md`](../docs/real-data-provenance.md) for license, checksum, acquisition metadata, and the required paper citation.
